## Featured Projects
### Learning to Act: Methods of Reinforcement Learning
An overview of the history and foundations of Reinforcement Learning, covering three major approaches:
- Dynamic Programming
- Monte Carlo Methods
- Temporal Difference Learning
The project examines the benefits and limitations of each approach, including computational complexity, required prior knowledge, and the effects different methods can have on bias and variance.

### Steam Games Recommender
A content-based filtering recommendation system designed to provide personalized game recommendations on Steam.
- Processed a dataset containing 60,000+ observations
- Applied machine learning and statistical modeling techniques
- Used Pandas for data processing and analysis
- Used Scikit-Learn for machine learning
- Used Matplotlib for data visualization
